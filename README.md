- Learning core DSA concepts step by step
- Practicing for coding interviews

## 🚀 Getting Started

### Prerequisites

- [Python 3.8+](https://www.python.org/downloads/) installed on your system
- [Git](https://git-scm.com/) (optional, for cloning)

### Clone the Repository

```bash
git clone https://github.com/sherkhanesamarth24-alt/DSA-With-Python.git
cd DSA-With-Python
```

### Run a Program

```bash
cd 06_Recursion
python gcd_using_recursion.py
```

> Replace the file name with any program from the folder you want to run.

## 💡 How to Use This Repo

1. Pick a topic folder that you want to practice.
2. Try solving the problem **on your own first**.
3. Compare with the solution in the repo.
4. Understand the time and space complexity.
5. Re-write the solution from memory for better retention.

## 🤝 Contributing

Contributions are welcome! To add a new problem or improve an existing solution:

1. Fork this repository
2. Create a new branch: `git checkout -b feature/new-problem`
3. Add your solution in the correct topic folder
4. Commit your changes: `git commit -m "Add <problem name>"`
5. Push to your branch: `git push origin feature/new-problem`
6. Open a Pull Request

### Guidelines

- Use clear and meaningful file and function names
- Add comments explaining the approach
- Mention time and space complexity where possible
- Keep code clean and follow PEP 8 style
